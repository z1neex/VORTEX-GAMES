# VORTEX Arcade

Каталог мини-игр без регистрации, без серверов и без базы. Работает на GitHub Pages.

## Структура
- `index.html`, `style.css` — страница и стили
- `app.js` — каталог, поиск, категории, загрузка игр
- `lib.js` — общие функции (холст, кнопки, управление) и `registerGame`
- `games/*.js` — каждая игра в отдельном файле

## Как добавить новую игру (без правки других файлов)
1. Создай файл в папке `games/`, например `games/tetris.js`.
2. Напиши в нём:

```js
registerGame('tetris', {
  title: 'Тетрис',
  cat: 'Головоломки',          // категория из списка или новая
  emoji: '🧱',
  desc: 'Собирай линии',
  start(el){
    // рисуй игру внутри el (холст: cv(el,w,h), кнопки: btn(el,текст,функция))
    const t=setInterval(()=>{/* логика */},16);
    return()=>clearInterval(t);   // остановка при выходе из игры
  }
});
```

3. Загрузи файл в папку `games/` на GitHub (Add file → Upload files) и подожди 1–2 минуты.
Игра появится в каталоге сама: сайт читает список файлов папки `games/` через GitHub.

## Как загрузить на GitHub Pages
1. Создай публичный репозиторий, например `arcade`.
2. Загрузи `index.html`, `style.css`, `app.js`, `lib.js` в корень, а папку `games/` со всеми файлами игр сохрани как есть.
3. **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
4. Сайт откроется по адресу `https://твой-логин.github.io/arcade/`.

## Что важно знать
- Список игр берётся через GitHub API. Если сайт открыт без интернета или лимит запросов исчерпан (60 в час с одного адреса), используется запасной список из `app.js`, и новые игры не появятся, пока не добавить их туда.
- Прогресс и рекорды хранятся только в браузере, аккаунтов нет.
