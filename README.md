# VORTEX Arcade

Каталог мини-игр без регистрации, без серверов и без базы данных. Работает только на GitHub Pages.

## Файлы
- `index.html` — страница (каталог и экран игры)
- `style.css` — стили
- `app.js` — каталог, поиск, категории, открытие игр
- `games.js` — все игры (объект `GAMES`)

## Как загрузить на GitHub Pages
1. Создай публичный репозиторий, например `arcade`.
2. **Add file → Upload files**, загрузи все четыре файла в корень.
3. **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
4. Сайт откроется по адресу `https://твой-логин.github.io/arcade/`.

## Как добавить свою игру
В `games.js` внутри `GAMES` добавь блок (запятая перед ним):

```js
mygame:{title:'Моя игра',cat:'Аркады',emoji:'🎯',desc:'Коротко о правилах',start(el){
  // рисуй игру внутри el
  const t=setInterval(()=>{/* логика */},16);
  return()=>clearInterval(t); // остановка при выходе из игры
}},
```

Подсказки: `cv(el,w,h)` создаёт холст, `btn(el,текст,функция)` — кнопку, `controls(el,(k,on)=>{})` даёт стрелки, WASD и экранные кнопки для телефона.

## Что важно знать
- Прогресса и рекордов нет: всё хранится только в памяти открытой вкладки. Это сделано специально.
- Каталог статичен. Чтобы добавить игру, нужно изменить файл на GitHub.
- Если нужна бесконечная коллекция игр от пользователей, это уже потребует сервер.
